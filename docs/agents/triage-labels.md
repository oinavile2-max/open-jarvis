# Vocabulário de triagem

Mapa local de referência. Este arquivo não cria labels nem altera issues no GitHub.

| Papel | Label |
|---|---|
| Aguardando triagem | `needs-triage` |
| Informação necessária | `needs-info` |
| Pronto para agente | `ready-for-agent` |
| Ação humana necessária | `ready-for-human` |
| Fora do escopo | `wontfix` |

Use essas labels em trabalho de triagem solicitado. Consulte primeiro as labels existentes no repositório antes de criar novas.
