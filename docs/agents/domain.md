# Documentação do domínio

Este repositório usa um único contexto: JARVIS OS Windows.

- Vocabulário: `GLOSSARY.md` na raiz. Leia quando a tarefa envolver termos do produto ou das interfaces.
- Decisões arquiteturais: `docs/adr/`. Leia as decisões pertinentes à área alterada.
- Atualize definições e decisões com evidências do código; não invente capacidades ainda não implementadas.
- Quando a decisão mudar, registre o motivo e substitua explicitamente o entendimento anterior.
